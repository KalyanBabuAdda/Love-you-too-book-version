# Memories — Sriram & Vasanthi

GitHub Pages-ready static website. No build step is required.

## Publish on GitHub Pages
1. Open your GitHub repository named **Memories**.
2. Upload everything inside this folder to the root of the repository (`index.html`, `styles.css`, `script.js`, `assets`, and `landing-pages`).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait a minute or two, then open your GitHub Pages URL.

All links in this project are relative, so it works under a project URL such as:
`https://YOUR-USERNAME.github.io/Memories/`

## Important
The ThreeUI-inspired interactive memory book is preserved in:
`landing-pages/memories-book.html`

Its page-curl engine is kept separate from the main site, so you can continue editing it without affecting the rest of the website.
